## ⭐ Featured: `ata` — meeting → document, fully offline

A tool I built and use daily. **Go** orchestrating **ffmpeg**, **Whisper** (whisper.cpp) and an **LLM**: it records a meeting, transcribes it **100% locally** — the audio never leaves the machine, an LGPD requirement of the use case — and generates three document types: meeting minutes, technical spec, and requirements gathering.

```
  🎙️  record  ──▶  🔊 ffmpeg  ──▶  📝 whisper.cpp  ──▶  🧠 LLM  ──▶  📄 doc
                                     (offline)          (swappable)
```

- 🗂️ **One system prompt per document type, versioned in a file** — iterable without recompiling — plus a domain glossary injected as context, so the model can tell signal from noise.
- 🔌 **Multi-backend behind one interface**: local model (Ollama / gemma3) or a headless CLI, swapped by flag without touching the caller.
- 📏 **Explicit token budgeting** — estimates transcript + prompt against a real output reserve and **fails with a clear error** when it doesn't fit the window, instead of letting the model truncate in silence.
- 🐛 **A real debugging story**: on a 58-minute meeting the transcript collapsed into repetition halfway through — the decoder was feeding its own error back as context for the next window. Isolating the decoding windows brought the whole meeting back.
- 📊 **Decided with numbers, not vibes**: a build-vs-buy study over a measured corpus (18 meetings, 34 documents, 11.6 h of audio) and a cost calculator with explicit per-model assumptions. Verdict: token cost is noise — the real decision is audio privacy and engineering hours.
